# lwccia.

Portfolio and website for lwccia., producer and mixing engineer based in France.
Features a beat catalog, latest releases, and direct contact.

## Preview

![Home](/assets/screenshot-home.png)
![Contact](/assets/screenshot-contact.png)

---

## Features

- Beat catalog with genre and BPM filters
- Integrated audio player
- YouTube videos page
- Contact page
- Secured admin interface

## Stack

 - Back-end  : Python / Flask
 - Database : SQLite
 - Front-end : HTML / CSS / JavaScript
 - Deployment : Railway
